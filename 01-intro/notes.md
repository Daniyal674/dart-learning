# 01 - Introduction to Dart

## What is Dart?

Dart is a programming language created by Google. It was built to make
writing apps fast and easy — whether that app runs on a phone, in a
browser, or on a server.

Dart code can be compiled two ways:

- **Native code** — fast, runs directly on device (used for mobile, desktop).
- **JavaScript** — runs in web browsers.

## Why learn Dart?

- **Flutter** — Google's toolkit for building mobile, web, and desktop apps
  from one codebase. Flutter is written in Dart, and you write your app
  logic in Dart too. No Dart, no Flutter.
- **Backend** — Dart also works for servers now, using frameworks like
  Shelf or Dart Frog. So you can build an API and a mobile app with the
  same language.
- **Easy to read** — Dart's syntax is close to Java, JavaScript, and C#.
  If you know Dart, picking up those languages later is much easier.
- **One language, two jobs** — less time switching between different
  languages for frontend and backend work.

## Setup

1. Install the Dart SDK (or install Flutter, which includes Dart).
2. Install VS Code.
3. In VS Code, install the **Dart** extension (search in Extensions tab).
   - If you plan to use Flutter too, install the **Flutter** extension —
     it installs Dart support automatically.
4. Create a file ending in `.dart`, for example `main.dart`.
5. Every Dart program needs an entry point — a function called `main()`.
   This is where the program starts running.
6. Run the file from the terminal:

```bash
    dart run main.dart
```

## Summary

Dart is the language behind Flutter, and it now works for backend code
too. It's beginner-friendly, has clean syntax, and lets you build across
mobile, web, desktop, and server with one skill set.
