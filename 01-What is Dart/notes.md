# What is Dart, and why learn it?

Dart is a programming language made by Google. It's the language behind **Flutter**, which is used to build apps for Android, iOS, web, and desktop from a single codebase. Outside of Flutter, Dart can also run on servers and command-line tools, which is why it works for backend development too.

## A few reasons people learn Dart

* **Essential for Flutter:** It's the only language Flutter supports, so if you want to build Flutter apps, Dart isn't optional.
* **Beginner-Friendly:** It's easy to read and write. The syntax is clean and highly accessible.
* **High Performance:** It compiles to native code, ensuring apps run fast.
* **Strong Tooling:** It has excellent tooling support in IDEs like VS Code (featuring hot reload, helpful error messages, and a built-in formatter).
